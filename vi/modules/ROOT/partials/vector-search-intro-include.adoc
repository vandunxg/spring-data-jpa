Để sử dụng Hibernate Vector Search, bạn cần thêm các dependency sau vào project.

Ví dụ sau minh họa cách cấu hình các dependency trong Maven và Gradle:

[tabs]
======
Maven::
+
[source,xml,indent=0,subs="verbatim,quotes",role="primary"]
----
<dependencies>
    <dependency>
      <groupId>org.hibernate.orm</groupId>
      <artifactId>hibernate-vector</artifactId>
      <version>${hibernate.version}</version>
    </dependency>
</dependencies>
----

Gradle::
+
====
[source,groovy,indent=0,subs="verbatim,quotes",role="secondary"]
----
dependencies {
    implementation 'org.hibernate.orm:hibernate-vector:${hibernateVersion}'
}
----
====
======

NOTE: Mặc dù có thể dùng `Vector` làm type cho query, bạn không thể dùng `Vector` trong domain model vì Hibernate yêu cầu vector type phải là mảng float hoặc double.
