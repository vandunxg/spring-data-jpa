[[query-by-example.running]]
Trong Spring Data JPA, bạn có thể sử dụng Query by Example với các Repository, như minh họa trong ví dụ sau:

.Query by Example sử dụng một Repository
====
[source, java]
----
public interface PersonRepository extends JpaRepository<Person, String> { … }

public class PersonService {

  @Autowired PersonRepository personRepository;

  public List<Person> findPeople(Person probe) {
    return personRepository.findAll(Example.of(probe));
  }
}
----
====

Property specifier chấp nhận các property names (chẳng hạn `firstname` và `lastname`). Bạn có thể điều hướng bằng cách nối các property với nhau bằng dấu chấm (`address.city`). Bạn cũng có thể tinh chỉnh bằng các matching options và case sensitivity.

Bảng sau đây cho thấy các option `StringMatcher` khác nhau mà bạn có thể sử dụng và kết quả khi áp dụng chúng cho một field có tên `firstname`:

[cols="1,2", options="header"]
.Các option của `StringMatcher`
|===
| Matching
| Kết quả logic

| `DEFAULT` (phân biệt hoa/thường)
| `firstname = ?0`

| `DEFAULT` (không phân biệt hoa/thường)
| `LOWER(firstname) = LOWER(?0)`

| `EXACT`  (phân biệt hoa/thường)
| `firstname = ?0`

| `EXACT` (không phân biệt hoa/thường)
| `LOWER(firstname) = LOWER(?0)`

| `STARTING`  (phân biệt hoa/thường)
| `firstname like ?0 + '%'`

| `STARTING` (không phân biệt hoa/thường)
| `LOWER(firstname) like LOWER(?0) + '%'`

| `ENDING`  (phân biệt hoa/thường)
| `firstname like '%' + ?0`

| `ENDING` (không phân biệt hoa/thường)
| `LOWER(firstname) like '%' + LOWER(?0)`

| `CONTAINING`  (phân biệt hoa/thường)
| `firstname like '%' + ?0 + '%'`

| `CONTAINING` (không phân biệt hoa/thường)
| `LOWER(firstname) like '%' + LOWER(?0) + '%'`

|===

NOTE: JPA không hỗ trợ regex-matching.
