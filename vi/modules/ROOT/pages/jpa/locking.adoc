[[locking]]
= Locking

Để chỉ định lock mode sẽ được dùng, bạn có thể sử dụng annotation `@Lock` trên các query method, như ví dụ sau:

.Định nghĩa lock metadata trên query methods
====
[source, java]
----
interface UserRepository extends Repository<User, Long> {

  // Plain query method
  @Lock(LockModeType.READ)
  List<User> findByLastname(String lastname);
}
----
====

Khai báo method này khiến query được kích hoạt sẽ đi kèm với một `LockModeType` là `READ`. Bạn cũng có thể định nghĩa locking cho các CRUD method bằng cách redeclare chúng trong repository interface của bạn và thêm annotation `@Lock`, như ví dụ sau:

.Định nghĩa lock metadata trên CRUD methods
====
[source, java]
----
interface UserRepository extends Repository<User, Long> {

  // Redeclaration of a CRUD method
  @Lock(LockModeType.READ)
  List<User> findAll();
}
----
====
