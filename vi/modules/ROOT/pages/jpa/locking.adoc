[[locking]]
= Locking

Để chỉ định lock mode sẽ được sử dụng, bạn có thể dùng annotation `@Lock` trên các query method, như trong ví dụ sau:

.Định nghĩa lock metadata trên các query method
====
[source, java]
----
interface UserRepository extends Repository<User, Long> {

  // Query method thông thường
  @Lock(LockModeType.READ)
  List<User> findByLastname(String lastname);
}
----
====

Khai báo method này khiến query được thực thi được gắn `LockModeType` là `READ`. Bạn cũng có thể thiết lập locking cho các CRUD method bằng cách redeclare chúng trong repository interface và thêm annotation `@Lock`, như trong ví dụ sau:

.Định nghĩa lock metadata trên các CRUD method
====
[source, java]
----
interface UserRepository extends Repository<User, Long> {

  // Khai báo lại một CRUD method
  @Lock(LockModeType.READ)
  List<User> findAll();
}
----
====
