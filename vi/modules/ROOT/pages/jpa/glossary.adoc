= Glossary
:page-section-summary-toc: 1

AOP :: Aspect-oriented programming

Commons DBCP :: Commons DataBase Connection Pools - một thư viện của Apache Foundation cung cấp các implementation hỗ trợ pooling cho interface DataSource.

CRUD :: Create, Read, Update, Delete - Các thao tác persistence cơ bản.

DAO :: Data Access Object - Pattern tách biệt logic persistence khỏi object được persist

Dependency Injection :: Pattern truyền dependency của một component vào component đó từ bên ngoài, để component không phải tự lookup dependency. Để biết thêm thông tin, xem link:$$https://en.wikipedia.org/wiki/Dependency_Injection$$[https://en.wikipedia.org/wiki/Dependency_Injection].

EclipseLink :: Object-relational mapper triển khai JPA - link:$$https://www.eclipse.org/eclipselink/$$[https://www.eclipse.org/eclipselink/]

Hibernate :: Object-relational mapper triển khai JPA - link:$$https://hibernate.org/$$[https://hibernate.org/]

JPA :: Jakarta Persistence API

Spring :: Framework cho ứng dụng Java - link:$$https://spring.io/projects/spring-framework/$$[https://spring.io/projects/spring-framework]
