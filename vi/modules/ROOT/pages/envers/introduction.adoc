[[envers.what.is.spring.data]]
== Spring Data Envers là gì?

Spring Data Envers cung cấp các query Envers thông dụng trong repository của Spring Data JPA.
Điểm khác biệt so với các module Spring Data khác là nó luôn được sử dụng kết hợp với một module Spring Data khác: Spring Data JPA.

[[envers.what]]
== Envers là gì?

Envers là một https://hibernate.org/orm/envers/[module Hibernate] bổ sung khả năng auditing cho các entity JPA.
Tài liệu này giả định rằng bạn đã quen thuộc với Envers; tương tự, Spring Data Envers dựa trên việc Envers được cấu hình đúng cách.
